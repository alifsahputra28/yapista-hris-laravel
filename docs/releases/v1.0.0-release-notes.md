## Release Scope

Release ini memuat YAPISTA HRIS Core untuk empat role aktual: `super_admin`, `hr_admin`, `pegawai`, dan `panitia`.

Modul utama:

- Authentication, invitation onboarding, role landing, dan account security.
- Dashboard operasional Admin/HR dan employee self-service mobile/desktop.
- Unit kerja, jabatan, data pegawai, NUP, verifikasi, dan profil enam bagian.
- Keluarga, pendidikan, sertifikasi, bank/pajak/BPJS, serta dokumen privat.
- NIK terenkripsi dengan exact HMAC blind-index lookup dan masking.
- Random/revocable QR token, digital E-Card, event, participant, scanner, dan attendance.
- Laporan pegawai/kegiatan/kehadiran, export XLSX, dan import Excel pegawai.

## Finalization Highlights

- NUP tetap memakai `employees.employee_number`, plaintext, nullable untuk draft, unique, dan tepat 10 digit saat tersedia.
- Existing employee ber-NUP valid mengikuti transisi verified, metadata verifier, dan satu active QR.
- Registrasi undangan kini mengarahkan pegawai ke onboarding profil. Pegawai existing yang sudah verified menggunakan tiga langkah opsional dan tetap mempertahankan NUP, QR, serta E-Card; pegawai baru tanpa NUP tetap menjalani enam langkah wajib sebelum verifikasi HR.
- Pegawai verified dapat memperbarui data tambahan kapan saja tanpa membuka verifikasi ulang. Field resmi kepegawaian tetap read-only dan submission ulang oleh pegawai verified ditolak aman.
- Change-impact regression onboarding lulus 145 test / 1.263 assertion; full regression lulus dua kali. Browser smoke lokal memuat login normal, sedangkan alur authenticated diverifikasi melalui feature tests tanpa membuat atau mereset credential UAT.
- Wizard enam langkah pegawai baru dan form turunannya kini memakai focus layout tanpa sidebar, hamburger, breadcrumb, footer, atau bottom navigation. Pegawai verified tetap memakai layout portal normal. Browser QA read-only lulus pada 1440x900 dan 390x844 tanpa horizontal overflow atau console error.
- Jabatan wajib berasal dari unit pegawai; duplicate master data dan relasi inti dilindungi aplikasi/database.
- Dokumen/foto pegawai berada pada private storage dan diakses melalui authorization backend.
- Public employee orphan files telah dipindah ke private quarantine; tidak ada permanent deletion.
- QR tidak memuat NUP, NIK, employee ID, email, atau data pribadi sebagai payload langsung.
- Scanner attendance menerima secure token sebagai standar utama dan exact 10-digit `employees.employee_number` sebagai kompatibilitas kartu lama yang terbatas pada attendance.
- Kompatibilitas NUP lama dikendalikan oleh `ATTENDANCE_ALLOW_LEGACY_NUP_QR`; default transisi aktif dan dapat dinonaktifkan tanpa perubahan kode.
- Halaman Scan Kehadiran kini memakai Focus Mode khusus: sidebar, hamburger, breadcrumb, dan footer Admin dihilangkan hanya pada scanner, dengan header event ringkas, area scanner lebar, hasil scan terakhir, riwayat terbaru, dan input manual berprioritas sekunder.
- Autofocus dan alur HID scanner dipertahankan; Enter mengirim payload ke endpoint scanner yang sama dan fokus kembali setelah success, duplicate, invalid, atau nonparticipant.
- Detail Pegawai Admin/HR kini menampilkan profil master lengkap dari relasi aktual: pribadi, kepegawaian, kontak/alamat, kontak darurat, keluarga, pendidikan, sertifikasi, administrasi/bank/BPJS, dokumen, verifikasi, dan kelengkapan profil.
- NUP tetap utuh; NIK, nomor KK, NIK keluarga, nomor ijazah/sertifikat, rekening, pajak, dan BPJS ditampilkan tersamarkan. Raw QR, hash, ciphertext, dan private storage path tidak dirender.
- System-wide Indonesian UI copy was standardized for clarity and terminology consistency. Terminologi pengguna kini konsisten memakai Pegawai, NUP, Unit Kerja, Kegiatan, Kehadiran, Verifikasi, Masuk/Keluar, serta Unggah/Unduh; pedoman berkelanjutan tersedia di `docs/ui/system-copywriting-guideline.md`.
- UAT memperbaiki tiga issue HIGH: upload dokumen verified employee, confirmation modal submit, dan approval profile/NUP/QR.

## Known Limitations And Deferred Items

- PDF download E-Card belum menjadi fitur v1; E-Card browser tetap tersedia.
- Physical QR/2D scanner belum diuji; application HID/Enter/focus flow telah lulus.
- Legacy NUP QR bersifat transitional dan lebih mudah dipalsukan daripada secure token; penerbitan kartu baru tetap wajib memakai secure/revocable token dan fallback ini harus dipensiunkan setelah kartu lama selesai diganti.
- External SMTP delivery belum diuji; application mail flow melalui test/log driver lulus.
- Production hosting, domain/DNS, HTTPS/TLS, secret store, backup destination, dan monitoring belum tersedia dalam sesi ini.
- Self-host font/CSP strict, import volume optimization, large XLSX streaming, dan cleanup asset legacy berada di post-v1 backlog.

Deployment hanya boleh memakai exact release candidate SHA dan lockfile. Production wajib memiliki HTTPS, document root ke `public/`, stable `APP_KEY` dan `EMPLOYEE_NIK_LOOKUP_KEY` yang berbeda, MySQL 8.x, private storage, least-privilege permissions, backup/rollback, serta monitoring minimum.
